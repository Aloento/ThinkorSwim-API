## 下单草稿 id 规则（关键，勿改）

```
CONFIRM 与 SUBMIT 必须复用同一 header.id（草稿态由服务端按 service+id 保存）。
换 id 提交 = "Can not submit while prices are not available!"。
orderId 从 SUBMIT 后的 patch /orders/0/orderId 读取（task-1 合并 patch 后即可见）。
```
