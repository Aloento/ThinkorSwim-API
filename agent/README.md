## 一页结论

1. **工程基线健康**：Node 26 下 install/build/test/lint 全绿。
2. **线上协议骨架未死**：端点、`ver 27.*.*`、`json-patches-structured` 握手、2s 心跳
   实测有效；但服务器 build 已前进约 300 个版本，**具体服务必须逐服务黑盒普查**。
3. **最大风险在认证生命周期**（refreshToken 有存无用、无重连、puppeteer 登录无法过
   MFA）与**响应路由按 service 不按 id**（并发串台 + 下单结果拿不到）。
4. 重构按 05 的六个阶段推进；黑盒测试按 04 执行，**写操作只进模拟盘，真实账户只读**。
