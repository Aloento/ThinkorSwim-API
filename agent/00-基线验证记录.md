## 2. 线上黑盒探针（无凭据，匿名）

工具：[agent/tools/probe-ws.mjs](tools/probe-ws.mjs)（只做连接+握手，不下单不查账户）。

```
+0.98s  OPEN                                        # wss://thinkorswim-services.schwab.com/Services/WsJson
+0.98s  SENT  {"ver":"27.*.*","fmt":"json-patches-structured","heartbeat":"2s"}
+1.14s  RECV  {"session":"3235_20252fddfd041b84","build":"27.2640.4-Q3","ver":"27.*.*"}
+3.13s  RECV  {"heartbeat":2000}
+5.13s  RECV  {"heartbeat":4001}
+7.13s  RECV  {"heartbeat":6001}
+9.13s  RECV  {"heartbeat":8001}
```

### 结论

1. **端点、握手协议、`ver: 27.*.*`、`json-patches-structured` 帧格式仍然有效**——一年停更
   并没有导致协议大版本翻车，这是好消息。
2. **服务器 build 已从 `27.2323.x` 前进到 `27.2640.4`**（仓库内测试 fixture 还停留在
   `27.2323.3-B0`）。约 300 个 build 的迭代意味着具体服务参数、字段名、错误结构可能已漂移，
   必须黑盒逐服务验证。
3. 握手时 `Sec-WebSocket-Extensions: permessage-deflate` 必须与服务协商成功：
   探针第一次以 `perMessageDeflate: false` 连接被服务器直接关闭（close 1006，
   "Server sent a Sec-WebSocket-Extensions header but no extension was requested"）。
   当前库经 `isomorphic-ws`/`ws` 默认开启 deflate，行为与线上一致；**重构时不要“优化”掉它**。
4. 心跳是**服务器单向推送**（每 2s 一个 `{"heartbeat":n}`），客户端无需回包；
   超过一段时间无客户端消息是否会踢线，需要带 token 的用例来验证（列入黑盒测试 B 组）。
