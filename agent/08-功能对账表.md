## 2. 结论

- **服务目录**：`ApiService` 77 项 = bundle 全集 + 实测发现（含 `quotes/options/centered`
  等证伪项注明）。68 个 handler 类 **68/68 全部可达**（task-14 收尾最后 3 个：
  order_events 派发、alerts/subscribe、workingOrders 查表风格）。
- **验证分层**：核心交易/行情/账户/自选/告警/指标/筛选器目录全部真实服务器端到端通过
  （`smoke-lib.mjs` 18 断言 exit 0）；🔧 项均具备参数级证据（错误帧自曝枚举/bundle 调用点
  逐字），仅缺真实账户权限下的成功帧——不是实现缺口。
- **确认不存在/已证伪**（勿再探测）：user_preferences、social_view、screeners、news、
  fundamental_history、trans_history、watchlist/get_all、account_history、tax_lots、
  order_preview、predict/quotes/options、quotes/options/centered（06 §4/§5）。
- **网页版功能 → API 完整性**：上表覆盖网页版全部可操作面板；唯一不覆盖的是纯前端功能
  （UI 布局、本地回测、导出 CSV 等），不属于 wsjson API 范畴。
